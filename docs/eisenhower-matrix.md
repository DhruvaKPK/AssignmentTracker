# Eisenhower Matrix – AssignmentTracker

## Do – MVP (Urgent & Important)
- Add, edit, delete, and view assignments.
- Sort assignments by due date and priority.
- Mark assignments as completed and save data to a CSV file.

## Schedule – V2.0+ (Important & Not Urgent)
- Add deadline reminders and notifications.
- Create a weekly calendar view.
- Track assignment completion statistics.

## Delegate – Use a Library (Urgent & Not Important)
- Use LocalDate and DateTimeFormatter for dates.
- Use ArrayList and Comparator for storing and sorting assignments.
- Use Scanner and Java file I/O for input and saving data.

## Delete – Cut It (Not Important & Not Urgent)
- AI-generated study schedules.
- Social features for sharing assignments.
- Custom themes and animations.
